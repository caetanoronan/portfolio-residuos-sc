Deploy no Render.com

📌 Pré-requisito: Conta no Render.com conectada ao GitHub

3.1 Criar Web Service

  1. Acesse dashboard.render.com
  2. Clique em "New +" → "Web Service"
  3. Conecte seu repositório GitHub: portfolio-residuos-sc
  4. Configure conforme abaixo:
Name: api-residuos-sc
Region: Oregon (US West)
Branch: main
Runtime: Python 3
Build Command: pip install -r requirements-api.txt
Start Command: uvicorn api.main:app --host 0.0.0.0 --port $PORT
Instance Type: Free

3.2 Variáveis de Ambiente (Opcional)

Se quiser habilitar autenticação:

API_KEYS_ENABLED=true
API_KEYS=sua-chave-secreta-123,outra-chave-456
ENVIRONMENT=production
CACHE_ENABLED=true
LOG_LEVEL=INFO
✅ Pronto! O Render fará o deploy automaticamente. Aguarde 3-5 minutos.
Ir para Render.com

Configurar Monitoramento (UptimeRobot)

Monitore se sua API está sempre online.

Configuração UptimeRobot (Gratuito):

  1. Crie conta em uptimerobot.com
  2. Adicione novo monitor (HTTP(s))
  3. URL: https://api-residuos-sc.onrender.com/health
  4. Intervalo: 5 minutos (plano free)
  5. Alertas: Email quando API ficar offline
✅ Benefícios: O UptimeRobot fará requisições regulares, evitando cold starts no Render!
Criar conta UptimeRobot
